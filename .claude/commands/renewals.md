Read CLAUDE.md. Consents expiring in the next 18 months or close to lapsing, with the RMA s124 renew-by date.

Run `npm run consent -- renewals`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

A negative days_to_renew_by means the six-month date has passed. Say that plainly and offer `/draft-renewal`.
