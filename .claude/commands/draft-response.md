Read CLAUDE.md. Draft the written response to an abatement notice or other regulator notice.

Run `npm run consent -- draft-response <notice>`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Writes a draft to drafts/. Read it, present the headline and path. Nothing is sent or lodged from here.
